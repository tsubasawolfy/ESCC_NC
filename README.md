# Niclosamide, EHMT2/G9a, and MYC/E2F in ESCC

This repository contains the analysis code accompanying the manuscript:

**Niclosamide Reduces Viability, EHMT2/G9a Expression, and MYC/E2F Transcriptional Signatures in Esophageal Squamous Cell Carcinoma Cells**

The study uses DepMap and exploratory bulk RNA-seq analyses to support a model in which niclosamide (NC) suppresses esophageal squamous cell carcinoma (ESCC) cell viability in association with EHMT2/G9a downregulation, LC3B-II accumulation, reduced MYC/E2F/G2M proliferative output, and stress-response transcriptional remodeling.

The repository is organized around the computational analyses used in the manuscript and supplementary appendix.

## Analysis Overview

### 1. DepMap / PRISM correlations

**The 1 October audit found a histology error in the historical cohort.** OE-19 (ACH-000679) is adenocarcinoma, although the archived DepMap lineage field labels it squamous. The default analysis now requires agreement with the archived Cellosaurus ESCC code C4024 and excludes OE-19. See [the audit](AUDIT_2026-10-01.md) for evidence and manuscript corrections.

The corrected cohort has **22 lines**. The response is PRISM primary-screen log2 viability fold change relative to DMSO at 2.5 µM niclosamide, not an IC50 or genetic-dependency score. Expression is already log2(TPM + 1). A negative correlation means higher baseline expression is associated with lower relative viability.

Of 19,221 expression profiles, 18,686 are testable and 535 are constant in this cohort. The historical selection rule requires **both Pearson and Spearman nominal p < .05**: 431 genes meet it (179 negative and 252 positive by Pearson sign). Pearson alone selects 630 genes. No gene passes BH FDR < .05.

**EHMT2 is no longer nominally significant after excluding OE-19:** Pearson r = −0.380076, p = .081016; Spearman rho = −0.384529, p = .077231. Its prior selection cannot be presented as a significant ESCC-wide association. The earlier 23-line calculation is available only through the explicit `historical_metadata_only` mode for audit reproduction.

### 2. GO/enrichR annotation

Script 02 takes the negative Pearson subset of the dual nominal-p list (179 genes for the corrected cohort). It retains complete statistics from GO Biological Process, Molecular Function and Cellular Component 2023. Methylation text matches and exact EHMT2 membership are separate from adjusted-p < .05 subsets; annotation alone does not establish enrichment.

A fresh authorized query on 1 October 2026 yielded three methylation text matches, none with adjusted p < .05, and no EHMT2 overlap membership. The prior methylation/EHMT2 prioritization rationale therefore does not survive the cohort correction.

Live queries require `enrichR`; offline replay uses archived CSVs and an exactly matching companion gene list. Historical archives for the old 204-gene query must not be reused for the corrected 179-gene query. Query dates, input fingerprints, library names and the library-default universe are recorded. Original query provenance remains unverified when only historical CSVs are available.

### 3. RNA-seq Upstream Workflow

Bulk RNA-seq was performed after 24 h NC treatment in CE81T2, OE21, and KYSE270 cells, with one control and one NC-treated sample per cell line. The upstream workflow archive documents processing with nf-core/rnaseq STAR-Salmon against GRCh38 with GENCODE Release 49 annotation.

The upstream folder includes workflow scripts, sample sheet, run records, Nextflow parameters, trace files, MultiQC-related software versions, and helper scripts. Original WSL paths are retained in run records as execution provenance.

### 4. RNA-seq Downstream Analysis

Downstream analyses use the gene-level TPM matrix. Analyses are restricted to protein-coding genes using GENCODE v49 annotation. Because there is one control and one NC-treated sample per cell line, replicate-aware differential expression testing was not performed. Instead, exploratory log2 fold changes are calculated as:

```text
log2FC = log2((TPM_NC + 0.1) / (TPM_Control + 0.1))
```

Positive log2FC values indicate higher expression after NC treatment. These ranked gene lists are used for KEGG/Reactome GSEA and Hallmark signature scoring.

## How to Run

Run commands from the repository root unless a subfolder README says otherwise.

### DepMap correlation analysis

Provide `metadata.csv`, `drug_sensitivity.csv` and `TPM_data.csv` (or one RDS per object), plus `input_manifest.csv` with `file`, `md5`, and `source` columns. Record the source release when known. The script checks each fingerprint before analysis. Metadata must include `Cellosaurus_NCIt_id`; expression must retain the original full `gene` profile identifier, because Entrez IDs are not unique in the archived data.

```r
Sys.setenv(DEPMAP_INPUT_DIR = "D:/analysis/pinned_inputs",
           DEPMAP_OUTPUT_DIR = "D:/analysis/new_run",
           DEPMAP_COHORT_MODE = "curated_escc")
source("01_DepMap_niclosamide_ESCC_correlation.R")
```

Use a new, empty output directory. Outputs include full and selected correlations, BH q values, cell IDs, exclusions, histology audit, candidate statistics, plotted pairs, and figures under `new_run/Figures/`.

For historical reproduction only, set `DEPMAP_COHORT_MODE="historical_metadata_only"` and choose a separate output directory. This mode includes the known histology conflict and must not be described as the corrected ESCC cohort.

### GO analysis

With `DEPMAP_OUTPUT_DIR` still pointing to the completed correlation run:

```r
# Offline replay: exact companion negative list plus three ontology CSVs.
Sys.setenv(DEPMAP_GO_CACHE_DIR = "D:/analysis/matching_go_archive")
source("02_GO_enrichR_negative_correlated_genes.R")
```

For a fresh web query, unset `DEPMAP_GO_CACHE_DIR` and install `enrichR` beforehand. Results go under `new_run/GO/`; a nonempty GO directory is rejected. An old 204-gene archive will be rejected for the corrected 179-gene analysis.

### RNA-seq Downstream Review Code

If the RNA-seq project root differs from the original analysis location, set `AUTOPHAGY_PROJECT_DIR` first:

```r
Sys.setenv(AUTOPHAGY_PROJECT_DIR = "F:/RNA_Seq/Autophagy")
setwd("04_RNA_seq_downstream")
source("00_run_NC_downstream_review_code.R")
```

Expected downstream inputs include the STAR-Salmon gene TPM matrix, sample metadata, and GENCODE v49 GTF file under `AUTOPHAGY_PROJECT_DIR`.

## Data Availability and Inputs

This repository contains code and run records, not all primary data files.

External or local inputs include:

- Fingerprinted DepMap/PRISM input snapshots originally obtained through the R `depmap` package; the archived source workspace was preserved locally.
- enrichR GO databases accessed through the online enrichR service.
- Raw FASTQ files for RNA-seq upstream processing.
- STAR/Salmon reference indices and GENCODE v49 annotation for RNA-seq.
- STAR-Salmon output matrices for RNA-seq downstream analysis.

For exact reproduction of manuscript outputs, archive the generated CSV/figure files, DepMap package version, enrichR query date, RNA-seq run records, and R package versions.

## Reproducibility Notes

- DepMap and enrichR are versioned or online resources and can change across package/database releases.
- The RNA-seq analysis is exploratory because each cell line has one control and one NC-treated sample. The code does not calculate DESeq2 P values or gene-level FDR values.
- Absolute WSL paths in RNA-seq upstream run records are intentionally retained as provenance of the original execution environment.

## Validation

## Analysis scope update on 1 October 2026

The TCGA survival component has been removed from the current manuscript and code set. An audit identified reversed Kaplan-Meier legend labels and a mismatch between fitted Cox contrasts and their reported interpretation. The earlier claim that combined high EHMT2/MYC expression was associated with poorer overall survival should not be relied on. The current repository supports the cell-focused manuscript described above.

The earlier code remains available in [Git history](https://github.com/tsubasawolfy/ESCC_NC/tree/aa20fbeedc6ad7325e1587277a467e63a7928c65) as a record of the previous analysis, not as validated survival-analysis code.
