# Niclosamide, EHMT2/G9a, and MYC/E2F in ESCC

This repository contains the analysis code accompanying the manuscript:

**Niclosamide Suppresses Esophageal Squamous Cell Carcinoma in Association with EHMT2/G9a Downregulation and Reduced MYC/E2F Proliferative Output**

The study uses DepMap/cBioPortal/TCGA and bulk RNA-seq analyses to support a model in which niclosamide (NC) suppresses esophageal squamous cell carcinoma (ESCC) cell viability in association with EHMT2/G9a downregulation, LC3B-II accumulation, reduced MYC/E2F/G2M proliferative output, and stress-response transcriptional remodeling.

## Analysis Overview

### 1. DepMap Prioritization

The DepMap analysis uses ESCC cell-line metadata, baseline RNA-expression profiles, and drug-sensitivity/dependency data from the R `depmap` package. Niclosamide dependency scores across 23 ESCC cell lines are correlated with baseline RNA expression. Genes with nominally significant negative correlations are treated as candidate baseline expression features associated with greater NC sensitivity.

This analysis supports the manuscript observation that 204 mRNAs showed negative correlation with NC dependency scores and that EHMT2/G9a was prioritized as a biologically relevant methylation-related candidate.

### 2. GO/enrichR Candidate Annotation

The enrichR analysis uses genes negatively correlated with NC dependency and queries GO Biological Process, Molecular Function, and Cellular Component 2023 databases. Methylation-related GO terms were used to prioritize EHMT2 and MEN1, with EHMT2 selected for downstream validation.

Because enrichR is a web resource, database content may change over time. For exact manuscript reproduction, archive the returned CSV files with the analysis date.

### 3. TCGA/cBioPortal Survival Analysis

The TCGA analysis uses the TCGA-ESCA PanCancer Atlas cBioPortal dataset filtered to ESCC cases. EHMT2 and MYC RNA expression are split by median values and used for Kaplan-Meier and Cox regression analyses.

The manuscript reports that combined high EHMT2 and high MYC expression was associated with poorer overall survival in an exploratory median-split analysis, including multivariate adjustment for age, sex, and tumor stage. This analysis is exploratory and should be validated in independent cohorts.

### 4. RNA-seq Upstream Workflow

Bulk RNA-seq was performed after 24 h NC treatment in CE81T2, OE21, and KYSE270 cells, with one control and one NC-treated sample per cell line. The upstream workflow archive documents processing with nf-core/rnaseq STAR-Salmon against GRCh38 with GENCODE Release 49 annotation.

The upstream folder includes workflow scripts, sample sheet, run records, Nextflow parameters, trace files, MultiQC-related software versions, and helper scripts. Original WSL paths are retained in run records as execution provenance.

### 5. RNA-seq Downstream Analysis

Downstream analyses use the gene-level TPM matrix. Analyses are restricted to protein-coding genes using GENCODE v49 annotation. Because there is one control and one NC-treated sample per cell line, replicate-aware differential expression testing was not performed. Instead, exploratory log2 fold changes are calculated as:

```text
log2FC = log2((TPM_NC + 0.1) / (TPM_Control + 0.1))
```

Positive log2FC values indicate higher expression after NC treatment. These ranked gene lists are used for KEGG/Reactome GSEA and Hallmark signature scoring.

## How to Run

Run commands from the repository root unless a subfolder README says otherwise.

### DepMap Correlation Analysis

```r
source("Script/revised/01_DepMap_niclosamide_ESCC_correlation.R")
```

Outputs are written to:

```text
Data/DepMap/
Figures/DepMap/
RDS/DepMap/
```

### enrichR GO Analysis

Run after the DepMap correlation script:

```r
source("Script/revised/02_GO_enrichR_negative_correlated_genes.R")
```

Outputs are written to:

```text
Data/DepMap/GO/
```

This step requires internet access to enrichR.

### TCGA KM Survival Plots

```r
source("Script/revised/03_TCGA_EHMT2_MYC_KM_risk_table_RStudio.R")
```

The script creates `survminer` Kaplan-Meier plot objects with risk tables and prints them for manual export from RStudio. It does not automatically save figure files.

### RNA-seq Downstream Review Code

If the RNA-seq project root differs from the original analysis location, set `AUTOPHAGY_PROJECT_DIR` first:

```r
Sys.setenv(AUTOPHAGY_PROJECT_DIR = "F:/RNA_Seq/Autophagy")
source("Script/revised/05_RNA_seq_downstream/00_run_NC_downstream_review_code.R")
```

Expected downstream inputs include the STAR-Salmon gene TPM matrix, sample metadata, and GENCODE v49 GTF file under `AUTOPHAGY_PROJECT_DIR`.

## Reproducibility Notes

- DepMap and enrichR are versioned or online resources and can change across package/database releases.
- The RNA-seq analysis is exploratory because each cell line has one control and one NC-treated sample. The code does not calculate DESeq2 P values or gene-level FDR values.
- TCGA EHMT2/MYC survival analyses are exploratory median-split analyses and require independent validation.
- Absolute WSL paths in RNA-seq upstream run records are intentionally retained as provenance of the original execution environment.

## Validation

Before GitHub packaging, the revised R scripts in `Script/revised/` were parsed successfully with R 4.4.3, and RNA-seq upstream Python helper scripts were checked with `python -m py_compile`. `Script/revised/code_manifest_sha256.csv` records file sizes and SHA256 checksums for the revised code set.
